# 画像圧縮・サイズ変更

Canvas API・File API・Blobを使い、画像をブラウザー内で圧縮、リサイズ、形式変換する静的Webアプリです。画像はサーバーへ送信しません。

## 機能
- JPEG・PNG・WebPの読み込み
- ドラッグ＆ドロップ
- 幅・高さの変更、縦横比維持
- 100%・75%・50%・25%のクイックサイズ
- JPEG・PNG・WebPへの形式変換
- JPEG・WebPの画質調整
- 変換後の概算容量表示
- 軽量化率の表示
- ファイル名指定とダウンロード

## 公開方法
GitHubで `image-optimizer` というPublicリポジトリを作成し、4ファイルをアップロードします。Settings → Pagesからmainブランチのrootを公開します。
